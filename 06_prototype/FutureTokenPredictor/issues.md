## HIGH

### H1 — Sync HTTP fetch blocks the async MCP event loop
**File:** `src/future_token_predictor/azure_pricing.py:189`  
**Status:** ✅ fixed  
`_fetch_from_api()` uses `httpx.Client` (sync). It's called from `calculate_cost()` → `predict()` inside an async MCP tool handler. On cold start or 24h TTL expiry, blocks the event loop for up to 30s.  
**Fix applied:** Pre-warm cache at server startup via `asyncio.to_thread(get_pricing_client()._get_cached_or_fetch)` in `_run()` before the stdio server starts.

### H2 — `_calibrator = False` sentinel — hidden 3-state variable
**File:** `src/future_token_predictor/predictor.py:22–36`  
**Status:** ✅ fixed  
`_calibrator` held `None` (untried), a `Calibrator` instance (live), or `False` (tried/failed). `False` is not type-safe and is invisible to readers.  
**Fix applied:** Added companion `_calibrator_init_attempted: bool = False`; removed the `False` sentinel.

## MEDIUM

### M1 — Stale cache after API failure causes retry storm
**File:** `src/future_token_predictor/azure_pricing.py:178–180`  
**Status:** ✅ fixed  
On `_fetch_from_api()` exception, `self._prices` was set to fallback but `self._timestamp` was NOT updated. Next call saw expired timestamp and retried the 30s fetch.  
**Fix applied:** Added `self._timestamp = time.time()` in the `except` block.

### M2 — Tier 3 called with empty string when `description=None`
**File:** `src/future_token_predictor/predictor.py:188`  
**Status:** ✅ fixed  
`client.estimate_tokens(description or "", profile)` sent `""` to the LLM when `predict(profile=...)` was called without a description.  
**Fix applied:** Guarded Tier 3 block with `if enable_tier3 and description:`.

### M3 — Prompt injection via bare `.format()` in LLM classifier
**File:** `src/future_token_predictor/llm_classifier.py:96`  
**Status:** ✅ fixed  
`_CLASSIFIER_PROMPT.format(description=description)` inlined user input into the instruction string with no structural boundary.  
**Fix applied:** Split into `[{"role":"system","content":_CLASSIFIER_SYSTEM}, {"role":"user","content":description}]`. Renamed constant to `_CLASSIFIER_SYSTEM`.

### M4 — `deployment_type: DeploymentRegion` parameter name contradicts type
**File:** `src/future_token_predictor/cost_calculator.py:18–53`  
**Status:** ✅ fixed  
Parameter was named `deployment_type` but typed `DeploymentRegion`. `DeploymentType` (standard/batch/provisioned) is a different enum.  
**Fix applied:** Renamed parameter to `deployment_region` in `cost_calculator.py` and `azure_pricing.py`.

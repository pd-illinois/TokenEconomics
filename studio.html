What is WAPE?

Weighted Absolute Percentage Error measures how far forecasts differ from actual usage.

WAPE = sum of absolute forecast errors / sum of actual values × 100.

Lower is better; 0% means an exact match. It can exceed 100%: forecasting 220 tokens when actual usage is 100 tokens gives 120% WAPE. It does not tell you whether forecasts were too high or too low.

These learning records compare token usage, not dollar cost or answer quality. Before and after compare the original and subsequent forecasts with the same measured samples. An unchanged result means no demonstrated improvement; it does not prove the forecast is accurate.

Missing evidence is unavailable, not zero. WAPE is undefined when total actual usage is zero. This metric is not a calibrated budget-risk guarantee.
